# 最終形態の設計図

## 最終的に目指す形

```text
AI社員オフィス SaaS
├ 組織・店舗・利用者
├ 店舗ごとのブランド設定
├ AI社員と役割
├ AI投稿室
├ 口コミ返信室
├ MEO確認室
├ 写真選定室
├ AI社員会議室
├ 活動・成果履歴
└ 管理・権限・契約（必要になった段階）
```

## 今回のMVPが担当する範囲

```text
店舗設定（コード内の1店舗）
  ↓
AI投稿室の4機能
  ↓
投稿履歴
```

## 将来へつながる接続点

- `businessId`：すべてのAI APIへ渡す
- `lib/businesses`：後でデータベース店舗設定へ置換
- `lib/prompts`：AI社員ごとに独立して改善
- `lib/server/post-history-repository.ts`：店舗別履歴へ切替
- `features`：部屋・機能単位で増設
- `lib/ai-employees.ts`：将来のAI会議室の参加者定義

最終形を先に全部作るのではなく、接続点だけを正しく置き、実証で必要性が確認できた機能から追加します。

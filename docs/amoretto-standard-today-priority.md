# AMORÉTTO STANDARD 今日の重要度フィルター

## 目的

営業カード、タイムライン、重要改訂、在庫確認が増えても、営業中に急ぐ項目を見失わないようにする。

## 表示区分

### 最優先

- アレルギー未確認
- 同伴の退店希望時刻未確認
- 当日のケーキ・花束確認が必要
- 記念日準備の未完了
- 「至急」の在庫不足

### 今日中

- 次に確認する営業タイムライン
- 未確認の重要改訂
- 通常の在庫不足・注文済み・入荷待ち

### 確認のみ

- 重大な未確認事項がない当日の予約

## 操作

- 初期表示は「すべて」
- 「最優先」「今日中」「確認のみ」で絞り込み可能
- 一覧項目を押すと、元の営業カードへ移動する
- 元データの登録・権限・個人情報表示は変更しない

## 実装方針

- `priority-flow.js` を `operations.js` の後に読み込む拡張レイヤーとする
- 既存の営業データを複製保存せず、画面上の確定済み表示から重要度を整理する
- 生成AI・外部APIは使用しない
- PWAキャッシュを v12 へ更新する

# スマホ運用ガイド

## 公開までの順番

1. PCで新しいMVPを確認
2. `npm run build` 成功を確認
3. GitHubへ保存
4. Vercelへ公開
5. 発行されたURLをスマホで開く
6. ホーム画面へ追加

## スマホで確認すること

- ログインできる
- 上部の機能選択が押しやすい
- 入力欄へ文章を入れやすい
- 生成ボタンが押しやすい
- コピーできる
- 投稿履歴が見やすい
- ログアウトできる

## ホーム画面へ追加

このMVPにはWebアプリ用のマニフェストとアイコンを入れています。

Vercel公開後、Chromeのメニューから「ホーム画面に追加」を選ぶと、アプリのように開けます。

## 注意

現在はAMORÉTTO専用の非公開実証版です。
URLとパスワードを不用意に共有しないでください。

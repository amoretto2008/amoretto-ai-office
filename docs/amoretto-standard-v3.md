# AMORÉTTO STANDARD V3

AMORÉTTO STANDARDは、長いマニュアルを読むためではなく、営業前・営業中にスタッフが短時間で店の基準へ戻るためのPWAです。

## スタッフができること

- 今日の合言葉、店主連絡、お知らせの確認
- 場面別マニュアルの閲覧
- ドリンクの材料・分量・作り方・使用グラスの確認
- グラスの用途・保管場所・扱い方の確認
- 開店前・営業中・閉店後チェック
- 7日間の研修と確認問題
- 全体検索、お気に入り、最近見た項目
- 引き継ぎ、気づき・事故、改善提案の送信
- オフライン時の保存済み内容の閲覧

## 店主ができること

店主モードはAI社員オフィスと同じパスワードでログインします。認証情報はHttpOnly Cookieで12時間保持し、ブラウザのJavaScriptからは読み取れません。

- 今日の合言葉と連絡事項の編集
- 期間・重要度付きのお知らせ管理
- 場面別マニュアルの追加・編集・並べ替え・非表示
- ドリンク、グラス、写真の管理
- チェックリストの管理
- 研修本文・確認問題の管理
- スタッフメモの確認、返信、対応済み処理
- 変更履歴の確認と復元
- JSONバックアップの書き出し・読み込み

## データの保存方針

### 全スタッフで共有

Supabase Storageに保存します。

- 店主連絡、お知らせ
- 場面別マニュアル
- ドリンク、グラス
- チェックリストの構成
- 研修内容
- スタッフから送信されたメモ
- 更新履歴（直近30版）

### 各スマホだけに保存

個人情報や日々の作業状態を必要以上に集めないため、次の情報はlocalStorageに保存します。

- 担当者名・役割
- 当日のチェック結果
- 今日の個人メモ
- 研修の完了状況
- お気に入り、最近見た項目

## V2からV3への移行

V2の共有データは削除しません。V3画面が不足項目を既定値で補い、店主が最初に「全スタッフへ保存」を実行した時点でV3形式へ更新します。

## 競合防止

店主が複数端末で同時編集した場合、保存開始時の最終更新日時と現在の共有データを比較します。別端末の更新がある場合は409を返し、古い画面からの上書きを防止します。

## 更新履歴と復元

共有保存のたびにスナップショットを作成し、直近30版を保持します。復元後も新しい版として保存するため、復元前の版を失いません。

## 画像

JPEG、PNG、WebP、GIFに対応し、上限は5MBです。対応ブラウザでは大きな静止画像を最大1600pxのWebPへ縮小してから送信します。

## 公開URL

`https://amoretto-ai-office.vercel.app/standard/index.html`

## 本番確認項目

1. Vercel buildが成功すること
2. 既存V2データが表示されること
3. 店主ログイン、保存、再読み込みができること
4. 別端末で共有更新が反映されること
5. 画像が表示されること
6. スタッフメモを送信・処理できること
7. 履歴復元後に新しいrevisionが作られること
8. PWAを再起動した際にV3キャッシュへ更新されること
